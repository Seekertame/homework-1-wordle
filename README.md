# MR2

## Что готово

MR1: словарь, выбор слова по seed и модель партии.

MR2: проверка ввода, подсчёт букв, победа и поражение.

## Запуск

Нужен JDK 25. Gradle ставить не нужно, в проекте есть `gradlew`.

```bash
./gradlew check
./gradlew test
./gradlew run
```

`check` запускает тесты и линтеры, то же самое проверяет CI. На Windows вместо `./gradlew` нужно писать `.\gradlew.bat`.

JDK новее 25 не подходит. На JDK 27 форматтер Spotless падает с ошибкой `NoSuchFieldError`.

## Устройство

Код игры лежит в пакете `academy.fiveletters.game`. Он не знает о консоли.

### MR1

`Dictionary` хранит список слов. При создании он приводит слова к нижнему регистру и проверяет их. Каждое слово должно состоять из 5 русских букв, и словарь не может быть пустым.

`GameStatus` описывает состояние партии: `IN_PROGRESS`, `WIN` или `LOSE`.

`GameSession` это одна партия. Она хранит загаданное слово, лимит попыток, историю попыток и статус.

`Game` содержит правила игры. Метод `startGame(dictionary, maxAttempts, seed)` начинает новую партию.

Словарь загружается в три шага. Метод `load` читает файл `dictionary.txt`. Метод `fromLines` убирает комментарии и пустые строки. Конструктор проверяет слова. Любой способ создать словарь проходит через конструктор, поэтому словарь всегда проверен.

### MR2

Метод `Game.applyGuess(session, guess)` проверяет ввод и записывает попытку.

`LetterMatcher` сравнивает ввод с загаданным словом и возвращает статус каждой буквы: `CORRECT` ✅, `PRESENT` 🟡 или `ABSENT` ❌.

`Attempt` это одна попытка: введённое слово и статусы его букв. История партии теперь хранит попытки, а не строки.

`GuessResult` это результат `applyGuess`. Он либо `Accepted` с попыткой, либо `Rejected` с причиной из `GuessError`.

## Решения

### MR1

Инварианты проверяются в конструкторах. Словарь не бывает пустым, число попыток больше нуля, а загаданное слово есть в словаре. Неправильный объект создать нельзя.

Неверное слово в словаре вызывает ошибку. Комментарии и пустые строки пропускаются, потому что это формат файла. А слово из 4 букв это ошибка в данных, и программа сразу о ней сообщает.

Слово выбирается через `new Random(seed)`. Слова хранятся в `List` в порядке файла, поэтому одинаковый seed всегда даёт одинаковое слово. У `Set` порядок не гарантирован.

Число использованных попыток не хранится отдельно. Это размер истории, поэтому два значения не могут разойтись.

Завершённая партия не принимает новые попытки. Если слово угадано на последней попытке, это победа.

Историю попыток и список слов нельзя изменить снаружи.

### MR2

Ввод приводится к нижнему регистру, пробелы по краям убираются, буква ё заменяется на е. Потом проверяется длина, что в слове только русские буквы и что слово есть в словаре.

Неверный ввод возвращает `Rejected` и не тратит попытку. Это обычная ситуация, поэтому здесь нет исключения. Исключение бросается, только если вызвать `applyGuess` на завершённой партии. Это ошибка в коде.

Метод `recordAttempt` виден только внутри пакета `game`. Попытку записывает только `applyGuess` после проверки ввода. Так неверный ввод не сможет потратить попытку.

Подсчёт букв отделён от проверки ввода. Так его можно проверить на любых строках, например на `оооом`, которого нет в словаре.

Каждая буква ответа используется один раз. Сначала отмечаются все ✅. Оставшиеся буквы ответа считаются свободными, и только ими закрываются 🟡.

## Тесты

### MR1

Обязательные тесты лежат в `mandatory/mr1`. Они проверяют размер словаря, длину слов, пустой словарь и seed.

Свои тесты лежат в пакете `game`. `DictionaryValidationTest` проверяет загрузку и проверку слов. `GameSessionTest` проверяет инварианты партии и смену статусов. `GameTest` проверяет начало партии.

### MR2

Обязательные тесты лежат в `mandatory/mr2`. Они проверяют ввод, подсчёт букв, победу и поражение.

Свои тесты лежат в пакете `game`. `LetterMatcherTest` проверяет подсчёт букв с повторами. `ApplyGuessTest` проверяет обработку ввода.
