# Игра «5 букв»

## Что готово

MR1: словарь, выбор слова по seed и модель партии.

MR2: проверка ввода, подсчёт букв, победа и поражение.

MR3: меню, несколько игр подряд и детерминированный режим по seed.

Бонусы: все шесть из задания. Уровни сложности, категории слов, подсказка, статистика за запуск, цветной вывод и повтор партии. Как они устроены и как их запускать, описано в [BONUSES.md](BONUSES.md).

## Правила игры

Программа загадывает слово из 5 русских букв. У игрока 6 попыток. После каждой попытки программа печатает значки и введённое слово. ✅ значит буква на своём месте. 🟡 значит буква есть в слове, но в другом месте. ❌ значит буквы в слове нет.

Каждая буква ответа учитывается один раз. Если загадано `сорок`, а введено `оооом`, результат будет ❌✅❌✅❌. Обе буквы о в ответе уже совпали на своих местах, поэтому остальные о получают ❌.

Слово можно вводить в любом регистре, ё считается как е. Слово должно быть из словаря. Неверный ввод не тратит попытку.

## Запуск

Нужен JDK 25. Gradle ставить не нужно, в проекте есть `gradlew.bat`.

Перед запуском в PowerShell нужно переключить ввод и вывод на UTF-8. Иначе русские буквы выводятся непонятными символами, а русские слова при вводе не принимаются. В cmd для этого есть команда `chcp 65001`.

```powershell
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
[Console]::InputEncoding = [System.Text.Encoding]::UTF8
```

Команды:

```powershell
.\gradlew.bat run -q --console=plain
.\gradlew.bat run -q --console=plain --args="--seed 42"
.\gradlew.bat run -q --console=plain --args="--seed 42 --show-answer"
.\gradlew.bat test
.\gradlew.bat check
```

Первая команда запускает игру. В меню нужно ввести 1, чтобы начать партию, или 2, чтобы выйти. Во время партии слова вводятся по одному в строке. Флаги `-q --console=plain` убирают служебный вывод Gradle.

Вторая команда запускает детерминированный режим. С одним и тем же seed программа загадывает одну и ту же серию слов. При seed 42 первое слово `шоссе`. Без `--seed` seed выбирается случайно и печатается в лог при запуске, поэтому любую игру можно повторить.

Флаг `--show-answer` в третьей команде печатает загаданное слово в начале каждой партии. Он работает и без seed.

Флаги бонусов `--level`, `--category`, `--color`, `--record` и `--replay` описаны в [BONUSES.md](BONUSES.md).

`test` запускает тесты. `check` запускает тесты и линтеры, эту же проверку выполняет CI.

## Устройство

Код игры лежит в пакете `academy.fiveletters.game`. Консоль лежит в пакете `academy.fiveletters.console`. Все константы собраны в классе `academy.fiveletters.Constants`: длина слова, число попыток, путь к словарю и другие.

Словарь лежит в файле `src/main/resources/dictionary.txt`.

### MR1

`Dictionary` хранит список слов. Метод `load` читает `dictionary.txt`, метод `fromLines` убирает комментарии и пустые строки, конструктор приводит слова к нижнему регистру и проверяет их.

`GameSession` хранит одну партию: загаданное слово, лимит попыток, историю попыток и статус. Статус описывает `GameStatus`: `IN_PROGRESS`, `WIN` или `LOSE`.

`Game.startGame(dictionary, maxAttempts, seed)` начинает новую партию.

### MR2

`Game.applyGuess(session, guess)` проверяет ввод и записывает попытку. Он возвращает `GuessResult`. Это либо `Accepted` с попыткой, либо `Rejected` с причиной из `GuessError`.

`LetterMatcher` сравнивает слово с ответом и возвращает статус каждой буквы: `CORRECT`, `PRESENT` или `ABSENT`.

`Attempt` хранит введённое слово и статусы его букв.

### MR3

`ConsoleGame` показывает меню, проводит партии и печатает результат. Ввод и вывод передаются ему извне, поэтому консоль можно проверить в тестах без запуска программы.

`GameSeries` получает из одного seed отдельный seed для каждой партии.

`LaunchOptions` разбирает аргументы запуска.

`Main` загружает словарь и запускает игру.

## Решения

### MR1

Инварианты проверяются в конструкторах. Словарь не бывает пустым, каждое слово в нём из 5 русских букв, лимит попыток больше нуля, загаданное слово есть в словаре. Неправильный объект создать нельзя.

Комментарии и пустые строки в файле словаря пропускаются, потому что это формат файла. Слово из 4 букв это ошибка в данных, поэтому программа сразу падает с сообщением.

Слова хранятся в `List` в порядке файла и выбираются через `new Random(seed)`. Поэтому одинаковый seed даёт одинаковое слово. У `Set` порядок не гарантирован.

Число использованных попыток не хранится отдельно, это размер истории. Так два значения не могут разойтись.

Завершённая партия не принимает попытки. Слово, угаданное на последней попытке, это победа.

Историю попыток и список слов нельзя изменить снаружи.

### MR2

Неверный ввод возвращает `Rejected`, а не бросает исключение. Опечатка игрока это обычная ситуация. Исключение бросается, только если вызвать `applyGuess` на завершённой партии, потому что это ошибка в коде.

Метод `recordAttempt` виден только внутри пакета `game`. Попытку записывает только `applyGuess` после проверки ввода, поэтому неверный ввод не может потратить попытку.

Подсчёт букв отделён от проверки ввода. Так его можно проверить на любых строках, например на `оооом`, которого нет в словаре.

Подсчёт идёт в два прохода. Сначала отмечаются все ✅. Оставшиеся буквы ответа считаются свободными, и только ими закрываются 🟡.

### MR3

Детерминированный режим сделан через числовой seed, а не через `--answer озеро`. Java на Windows получает аргументы в системной кодировке. Если в ней нет русских букв, как в английской Windows, слово приходит как `?????`, и настройка терминала это не исправляет. В флаге `--show-answer` русских букв нет, поэтому он работает везде.

Консоль не содержит правил игры. Она читает строки, вызывает `Game.startGame` и `Game.applyGuess` и печатает результат.

Программа сама читает и пишет текст в UTF-8, не полагаясь на флаги JVM.

Строка «Осталось попыток» печатается, пока партия идёт. После победы или поражения печатается только итог. Слово «попытка» склоняется по числу.

Если ввод закончился, программа завершается без ошибки. Неверные аргументы запуска выводят ошибку и завершают программу с кодом 2.

## Тесты

### MR1

Обязательные тесты в `mandatory/mr1` проверяют размер словаря, длину слов, пустой словарь и seed.

`DictionaryValidationTest` проверяет загрузку и проверку слов. `GameSessionTest` проверяет инварианты и статусы партии. `GameTest` проверяет начало партии.

### MR2

Обязательные тесты в `mandatory/mr2` проверяют ввод, подсчёт букв, победу и поражение.

`LetterMatcherTest` проверяет повторяющиеся буквы. `ApplyGuessTest` проверяет обработку ввода.

### MR3

Обязательные тесты в `mandatory/mr3` запускают программу и проверяют неверный пункт меню, несколько партий подряд и одинаковый вывод при одинаковом seed.

`ConsoleGameTest` проверяет формат вывода, ошибки ввода, конец ввода и склонение. `LaunchOptionsTest` проверяет аргументы. `GameSeriesTest` проверяет серию партий. `MainTest` проверяет код выхода при неверном seed.

Тесты бонусов описаны в [BONUSES.md](BONUSES.md).
